# 📱 iPhone Style Calculator

A premium, pixel-perfect iPhone-style calculator built using vanilla HTML, CSS, and modern JavaScript. 

## ✨ Features
- **Premium iOS Design:** Circular button layouts, native iOS color palettes, and active click state animations.
- **Dynamic Math Engine:** Real-time computation and error handling using JavaScript execution logic.
- **Smart Backspace (C):** Delete characters one by one instead of wiping out the entire display screen.
- **Global Reset (AC):** Complete screen layout wipeout with a single click.

## 🛠️ Tech Stack
- **Frontend:** HTML5 (Semantic Structure) & CSS3 (Flexbox Layouts)
- **Logic:** Modern JavaScript (ES6 DOM Events & String Manipulation)
